# اللغة التركية (tr) في تطبيق HudhudNest

التركية هي اللغة الرابعة الرسمية بعد العربية (RTL) والإنجليزية والألمانية. رمز اللغة `tr`، الثقافة `tr-TR`، الاتجاه LTR، الاسم الأصلي **Türkçe**.
هذا المستند يخص مستودع التطبيق. جانب الـ API (قاعدة البيانات، الترجمة الآلية للإعلانات، الإشعارات، البحث) في `docs/turkish-language.md` بمستودع الـ API.

## نظامان منفصلان (لا يُخلطان)

| النظام | ما هو | أين |
|---|---|---|
| **ملفات لغة الواجهة** | نصوص الواجهة الثابتة (أزرار، عناوين، رسائل) | `public/i18n/tr.json`، `public/i18n/legal/tr/*` |
| **الترجمة الآلية لنصوص الإعلانات** | عنوان ووصف وشارع الإعلان الذي كتبه المالك | الـ API (`ListingTranslations`) والواجهة تعرضه عبر `listing-translation.service.ts` |

يُختبران كلٌّ على حدة. ترجمة نص إعلان لا تمرّ بـ `tr.json`، و`tr.json` لا يمسّ نص أي إعلان.

## ما أُنجز

- **`LanguageService`**: `LangCode` يضم `tr`، قائمة اللغات `{code:'tr', label:'Türkçe', dir:'ltr'}`، التخزين كما في بقية اللغات (اختيار المستخدم يتقدم دائمًا ولا يُستبدل تلقائيًا).
- **اللغة عند أول زيارة** (`first-visit-language.ts`): التركية تُختار من لغة الجهاز فقط. **لا قاعدة بلد لتركيا** عن قصد (عرب تركيا). التفاصيل في `FIRST-VISIT-LANGUAGE.md`.
- **المحددات**: النافبار (قائمة منسدلة + درج الجوال)، صفحة الهبوط (بطاقة Türkçe)، حذف الحساب، صفحة `/download`، وصفحات العروض والإحالات.
- **`public/i18n/tr.json`**: 4117 مفتاحًا، تطابق كامل مع `en/ar/de` (نفس المفاتيح والعناصر النائبة `{{ }}`).
- **النصوص القانونية**: `public/i18n/legal/tr/privacy.json` و`terms.json` مع **تنبيه ظاهر في الصفحة** (`reviewNotice`) بأنها تنتظر مراجعة محامٍ تركي، ولم تُعالج متطلبات KVKK. التفاصيل في `docs/legal/LEGAL-REVIEW-REQUIRED.md` البند 11.
- **التواريخ والأرقام**: `localized-date.pipe.ts` يسجّل `tr` (يوم/شهر بالتركية)، `payments-format.ts` يعطي `tr-TR`، و`supported-preferences.ts` يربط `tr → tr-TR`. **عملة الإعلان المخزّنة لا تتغير** (تعرض بصيغة الأرقام التركية فقط، والليرة TRY موجودة سابقًا ضمن العملات).
- **مشاركة المحتوى والزواحف الاجتماعية**: `social-crawler.mjs` (`?lang=tr`)، `meta.service.ts` (`og:locale` = `tr_TR`)، وقوالب المشاركة في `offer-share.service.ts`.
- **iOS**: `tr.lproj/InfoPlist.strings`، `CFBundleLocalizations`، `knownRegions`، ومولّد `tools/lib/ios-config.mjs`. Android لا يملك موارد نصية مترجمة أصلًا.
- **الخريطة**: `map-picker` يعرض نصوصًا تركية ولا ينهار مع لغة غير معروفة (يرجع للعربية).
- **أخطاء الـ API**: `api-error.interceptor.ts` يعامل التركية مثل الألمانية حين تصل رسالة إنجليزية من الخادم.
- **التحقق من التغطية**: `npm run i18n:coverage` (قواعد صارمة: الوجود، عناصر نائبة متطابقة، الخط/السكربت، ونسخ الإنجليزية حرفيًا). النتيجة: `4117/4117 (100%)`، منها 17 قيمة مطابقة للإنجليزية **عن قصد** (أسماء علم/رموز مثل HudhudNest). **هذه النسبة تقيس الاكتمال لا الجودة**: المراجعة البشرية بمتحدث تركي مطلوبة.

## حدود معروفة (غير مخفية)

1. **أسماء الأماكن** (محافظات/أحياء) لا أعمدة تركية لها؛ تظهر بالإنجليزية في التركية (الأسماء لا تُترجم، وهو قرار QA Phase 16 D09 نفسه).
2. **ملاحظات الإصدار** (App update) لا عمود تركي؛ تعود للإنجليزية.
3. **النصوص القانونية التركية** تنتظر مراجعة محامٍ؛ KVKK غير مغطى.
4. جهاز تركي في ألمانيا/النمسا/سويسرا/ليختنشتاين يبدأ بالألمانية (قاعدة البلد تتقدم)؛ المستخدم يغيّرها بنقرة وتُحفظ.
5. تواريخ إشعارات البريد/الدفع تبقى `dd/MM/yyyy` ثابتة (كما بقية اللغات).
6. لم تُفحص النصوص التركية بعين متحدث أصلي، ولم تُجرَّب على أجهزة حقيقية (إلا محاكاة Chromium بمقاسين).
7. نصوص `title` وبيانات SEO تُبنى من مفاتيح الترجمة وتعمل بالتركية؛ لم نضف `hreflang` لأن الموقع لا يملك روابط مستقلة لكل لغة (اللغة تُحفظ بالمتصفح لا بالمسار)، ولا يصحّ إعلان `hreflang` بلا عناوين فعلية.

## النشر (يدوي، لا شيء يُنشر تلقائيًا)

1. دمج PR التطبيق في `main`، ثم PR `main → release` (merge commit)، ثم Publish على Netlify (يُفضّل تجميعه مع تغييرات أخرى: 15 رصيد/بناء).
2. **ترتيب الدمج:** يجب نشر الـ API (والـ Migrator) قبل التطبيق أو معه، وإلا فإن اختيار `tr` في الإعدادات يُرفض من الخادم (التحقق من لغة المستخدم) وستفشل طلبات `translation?lang=tr` بـ 400.
3. التطبيق الأصلي (Android/iOS) يحتاج إصدارًا جديدًا ليظهر `tr.lproj` وقائمة اللغات الأصلية؛ تحديث الويب وحده يكفي للمتصفح.

## التراجع

- تراجع الواجهة: إعادة `main` إلى الالتزام السابق (أو `revert` للـ PR). من اختار `tr` ثم تراجعنا: `LanguageService` يعامل لغة غير معروفة كالافتراضية (`ar`) فلا ينهار شيء.
- لا تغييرات بيانات في التطبيق (لا ترحيلات).
