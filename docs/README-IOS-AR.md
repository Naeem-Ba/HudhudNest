# تقرير تنفيذ دعم iOS

## النتيجة

تمت إضافة طبقة دعم iOS القابلة للدمج: اعتماديات Capacitor، إعداد مشترك أكثر أماناً، سكربت فحص، سكربت إنشاء ومزامنة على macOS، Privacy Manifest ابتدائي، ووثائق الإعداد والبناء والاختبار والإصدار.

## حدود التنفيذ

بيئة إنشاء الحزمة ليست macOS ولا تحتوي Xcode، لذلك لم يتم ادعاء إنشاء Workspace قابل للبناء أو تشغيل CocoaPods أو Archive أو اختبار iPhone. السكربت `npm run ios:setup` ينفذ تلك الخطوات على Mac ويوقف التنفيذ مبكراً إن كانت المتطلبات ناقصة.

## قرارات مهمة

- أضيف `@capacitor/ios` و`@capacitor/app` بإصدار رئيسي 8 لمطابقة Capacitor الحالي.
- أصبح `cleartext` معطلاً افتراضياً ولا يفعّل إلا عبر `CAPACITOR_ALLOW_CLEARTEXT=true` للتطوير المقصود.
- لم تضف أذونات Camera/Photos إلى Info.plist لأن المشروع لا يثبت Plugin أصلياً يطلبها؛ إضافة أذونات غير مستخدمة تزيد تدقيق الخصوصية.
- ملف Privacy Manifest الحالي يعلن عدم التتبع أو الجمع من التطبيق نفسه، لكنه يجب أن يراجع عند إضافة SDKs أو Analytics.
- Bundle Identifier الحالي عام نسبياً ويجب تثبيت معرف نهائي مملوك للعلامة قبل أول إصدار.
