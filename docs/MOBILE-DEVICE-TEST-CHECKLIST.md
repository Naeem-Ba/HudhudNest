# Phase 2 — قائمة اختبار Capacitor على أجهزة حقيقية

> لا تعتبر Phase 2 مكتملة إنتاجياً قبل تنفيذ هذه القائمة على جهاز Android فعلي، وعلى iPhone ذي notch/Dynamic Island عند توفر مشروع iOS.

## التحضير

```bash
npm install
npm run build:prod
npx cap sync android
npx cap open android
```

لـ iOS، بعد إضافة المنصة على macOS:

```bash
npm run build:prod
npx cap sync ios
npx cap open ios
```

## Android فعلي

- [ ] افتح التطبيق من شاشة البداية وتأكد أن الـ Navbar لا تدخل تحت شريط الحالة.
- [ ] افتح القائمة الجانبية؛ يجب ألا يُقطع أول أو آخر عنصر بسبب system bars.
- [ ] اضغط زر الرجوع والجـانب مفتوح؛ يجب أن يُغلق الدرج فقط، دون تغيير الصفحة ودون خروج التطبيق.
- [ ] اضغط زر الرجوع في صفحة داخلية؛ يجب الرجوع إلى الصفحة السابقة.
- [ ] اضغط زر الرجوع في `/home`؛ يجب الخروج من التطبيق.
- [ ] بدّل بين portrait وlandscape وأعد فحص الحواف الأربع.
- [ ] افتح لوحة المفاتيح في نموذج وتأكد من عدم ظهور تمرير دائم بعد إغلاقها.

## iPhone ذي notch أو Dynamic Island

- [ ] الـ Navbar تبدأ أسفل منطقة الحالة ولا يُحجب الشعار أو الأزرار.
- [ ] افتح الدرج وتأكد أن المحتوى لا يدخل تحت الـ notch أو Home Indicator.
- [ ] افحص portrait وlandscape.
- [ ] مرّر الدرج حتى آخر عنصر وتأكد من وجود مساحة آمنة فوق Home Indicator.
- [ ] افحص سلوك `100dvh` أثناء إظهار وإخفاء أشرطة Safari عند تشغيل نسخة الويب أيضاً.

## الجلسة والإشعارات والأذونات (على جهاز حقيقي: Android وiPhone)

لا يمكن اختبار هذه البنود إلا على جهاز؛ الاختبارات الآلية تغطي الملفات والمنطق فقط.

**الجلسة (خصوصًا iPhone، WKWebView يتعامل مع الكوكي بقواعده):**

- [ ] سجّل الدخول، أغلق التطبيق كليًا، افتحه بعد 20 دقيقة: ما زلت مسجّلًا.
- [ ] نفّذ عملية POST (مثلًا احفظ بحثًا أو أرسل رسالة): تنجح بلا طلب دخول جديد.
- [ ] سجّل الخروج ثم افتح التطبيق: صفحة الزائر، وبلا طلبات `auth/refresh` فاشلة متكررة.

**الإشعارات (الإذن يُطلب بزر في صفحة الإشعارات، لا عند الدخول):**

- [ ] بعد تسجيل الدخول لا تظهر نافذة إذن النظام وحدها.
- [ ] افتح الإشعارات: تظهر بطاقة «فعّل إشعارات الهاتف»؛ الضغط على الزر يُظهر نافذة النظام.
- [ ] بعد القبول تختفي البطاقة، ويصل إشعار تجريبي والتطبيق مغلق (Android: القناة «إشعارات هدهد نيست» ظاهرة في إعدادات الإشعارات).
- [ ] عند الرفض تظهر سطر توجيه إلى إعدادات الهاتف فقط، بلا زر.
- [ ] اضغط الإشعار: يفتح الشاشة المعنية.
- [ ] iPhone: بعد القبول يظهر رمز في جدول الأجهزة بالخادم بمنصة `ios`؛ إن لم يظهر فراجع APNs في Firebase و`GoogleService-Info.plist`.

**الأذونات:**

- [ ] نوافذ الموقع والكاميرا والصور تظهر بلغة الجهاز (عربي/ألماني/إنجليزي).
- [ ] Android: صفحة التطبيق في Play Console لا تعرض إذن «الصور والوسائط» أو «التخزين».

**الشاشة:**

- [ ] التنقل: افتح القائمة الجانبية، زر الإغلاق ظاهر ويعمل، والتركيز لا يخرج منها بالتبويب (لوحة مفاتيح خارجية).
- [ ] الوضع الداكن: الأسعار والأرقام والعناوين مقروءة في الرئيسية وقائمة العقارات.

## توثيق نتيجة الاختبار

سجّل لكل جهاز:

- الموديل وإصدار النظام.
- إصدار WebView أو Safari.
- اتجاه الشاشة المختبر.
- النتيجة: ناجح/فشل.
- لقطة شاشة أو تسجيل قصير عند الفشل.
