# مصفوفة الاختبار اليدوي للواجهات المتجاوبة

هذه المصفوفة هي معيار القبول لصفحات Phase 3. لا تُعتبر الصفحة منتهية حتى تُختبر عند العروض الثلاثة التالية فقط:

| الفئة | العرض | الاستخدام |
|---|---:|---|
| هاتف | 375px | أصغر عرض مستهدف عملياً |
| تابلت | 768px | انتقال التخطيط بين الهاتف والحاسوب |
| حاسوب | 1440px | تخطيط سطح المكتب الواسع |

## قواعد التنفيذ

- اختبر في Chrome أو Edge مع ضبط العرض رقمياً، وليس بالسحب التقريبي.
- نفّذ دورة واحدة على الأقل باللغة العربية RTL ودورة باللغة الألمانية أو الإنجليزية LTR.
- افحص الصفحة دون Zoom، عند 100%.
- أي تمرير أفقي غير مقصود يُعد فشلاً.
- أي عنصر تفاعلي أساسي أصغر من 44×44px على الهاتف يُعد فشلاً.
- سجّل الفشل برابط Screenshot أو Video، مع المسار والعرض واللغة.
- لا تعتبر DevTools بديلاً عن اختبار Capacitor على جهاز فعلي.

## الفحوص المشتركة لكل صفحة

نفّذ البنود التالية عند 375px و768px و1440px:

- [ ] لا يوجد horizontal overflow أو محتوى مقطوع.
- [ ] الـNavbar والمحتوى لا يتداخلان.
- [ ] العناوين والنصوص الطويلة تلتف دون كسر التخطيط.
- [ ] الصور لا تتمدد أو تتشوه، والـfallback يعمل.
- [ ] الأزرار والروابط قابلة للنقر، وحالات focus ظاهرة بالكيبورد.
- [ ] RTL وLTR لا يعكسان الأيقونات أو المسافات بشكل خاطئ.
- [ ] Loading وError وEmpty state لا تكسر الصفحة.
- [ ] تغيير العرض لا يترك Drawer أوOverlay في حالة عالقة.

## 1. Home + Navbar

المسارات: `/`, `/home`

- [ ] 375px: الشعار وأزرار Navbar لا تتزاحم، والقائمة المتنقلة تفتح وتغلق بالكامل.
- [ ] 375px: Mobile Drawer يستخدم كامل الارتفاع المرئي ولا يُقطع آخر عنصر.
- [ ] 375px: بطاقات العقارات عمود واحد وصورها واضحة دون تحميل حجم مبالغ فيه.
- [ ] 768px: الانتقال بين Navbar المكتبي والمتحرك لا يترك عناصر مكررة.
- [ ] 768px: شبكة البطاقات والمسافات متوازنة.
- [ ] 1440px: المحتوى لا يتمدد إلى عرض غير مقروء، والـgrid متناسق.
- [ ] جميع العروض: تغيير اللغة يغلق القوائم المفتوحة ولا يسبب قفزة تخطيطية كبيرة.

## 2. قائمة العقارات

المسارات: `/wohnungen`, `/properties`

- [ ] 375px: زر الفلاتر ظاهر وقابل للمس، والـFilter Drawer يغطي الشاشة دون قطع.
- [ ] 375px: حقول السعر والفلاتر عمودية ولا تتجاوز العرض.
- [ ] 375px: إغلاق الفلاتر يعيد التمرير الطبيعي للصفحة.
- [ ] 768px: شبكة النتائج لا تنتج بطاقة ضيقة أو نصاً متداخلاً.
- [ ] 1440px: الفلاتر والنتائج تستخدم المساحة دون فراغ مفرط.
- [ ] جميع العروض: pagination أو load-more لا يتداخل مع البطاقات.
- [ ] جميع العروض: الصور responsive وfallback لا يغير ارتفاع البطاقة فجأة.

- [ ] 1440px: العرض ثنائي العمود متوازن ولا يترك النص بعرض مفرط.

- [ ] 375px: رسائل التحقق تلتف ولا توسع الصفحة أفقياً.
- [ ] 768px: Brand panel مخفي أو معاد ترتيبه دون مساحة فارغة.
- [ ] 1440px: التقسيم بين brand وform متوازن.
- [ ] جميع العروض: حالات loading وinvalid credentials واضحة ولا تحرك النموذج بعنف.
