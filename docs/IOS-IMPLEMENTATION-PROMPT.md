# برومبت تنفيذ دعم iOS

أنت مهندس Mobile Principal ومتخصص Angular وCapacitor وiOS وDevOps. حلّل المشروع قبل التعديل، ثم أضف دعم iOS دون كسر Android أو الويب. وحّد إصدارات Capacitor، أضف `@capacitor/ios` و`@capacitor/app`، راجع `capacitor.config.ts`، امنع HTTP غير المشفر في الإنتاج، وأنشئ سكربت إعداد حتمي يعمل على macOS ويتحقق من Xcode وCocoaPods ثم يبني Angular ويضيف iOS ويزامن Plugins ويضبط Info.plist وPrivacy Manifest.

لا تضف أذونات غير مستخدمة. راجع Safe Area والكيبورد والاتجاهات وStatus Bar وHome Indicator. أنشئ وثائق عربية للبناء والاختبار والإصدار واستكشاف الأعطال. افصل بوضوح بين ما تم التحقق منه آلياً وما يتطلب Mac أو جهاز iPhone أو حساب Apple Developer. لا تدّع نجاح Archive أو App Store submission دون دليل. أخرج Git Patch وحزمة merge-ready وقائمة ملفات وتقرير مخاطر وخطوات دمج.
